Lizenzinstallation

Sie haben noch keine Lizenzdatei installiert oder die Lizenzdatei ist ungültig! Es muss daher erstmals (oder nochmals) eine gültige Lizenzdatei installiert werden.

Die Lizenzdatei trägt den Namen 'Key.dat' oder den Namen ihrer Firma (z.B. muster.dat) und befindet sich auf der CD oder auf der letzten Diskette. Es kann auch sein, dass Sie diese Datei von Ihrem Systemlieferanten als e-mail bekommen haben. Stellen Sie bitte sicher, dass Sie über eine Lizenzdatei verfügen um fortzusetzen.

Bitte legen Sie den Datenträger ein, auf dem sich die Lizenzdatei befindet (falls sie nicht auf einer Festplatte gespeichert ist) und betätigen Sie den Button Lizenz installieren. Öffnen Sie mit dem daraufhin erscheinenden Dialog die Lizenzdatei (Wählen Sie dazu gegebenenfalls das Laufwerk A:\ falls sich die Lizenzdatei auf einer Diskette befindet oder den Pfad ihres CD-ROM Laufwerkes oder der gewünschten Festplatte, je nach Speicherort der Lizenzdatei.
