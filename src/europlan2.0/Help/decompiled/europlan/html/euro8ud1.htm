Neuen Verteiler anlegen

Dieses Fenster dient zur Eingabe der wichtigsten Daten des Verteilers.

Eingabefelder:

Nummer: Geben Sie hier eine eindeutige Verteilernummer an. Diese Nummer muss eindeutig innerhalb des gesamten Projektes sein.

Bezeichnung: In diesem Eingabefeld können Sie eine beliebige Bezeichnung des Verteilers eingeben, die eine leichte Orientierung ermöglichen soll.

Regelkreis: Wählen Sie den Regelkreis, an den der Verteiler angeschlossen werden soll.

Hinweis: Sie sollten die Eigenschaften des neu angelegten Verteilers überprüfen, nachdem Sie in erstellt haben.

Bearbeitungsmöglichkeiten:

Je nach Einstellung in der Programmkonfiguration wechseln Sie mit Tab oder Enter zum nächsten Feld.

Mit dem Button Ok beenden Sie die Eingabe..
