Geschosse

Geschosse sind eine wichtige Gruppierungseinheit in EuroPlan. Alle Abhängigkeiten zwischen verschiedenen Räumen und Heizungssystemen sind auf das Geschoss beschränkt, in dem sie definiert sind. So kann z.B. eine Anbindeleitung eines Raumes im Erdgeschoss nicht durch einen Raum im Obergeschoss führen. Genauso wenig kann ein Raum im Keller an einen Verteiler im Erdgeschoss angeschlossen werden. Berücksichtigen Sie daher schon beim Anlegen der Geschosse den Verlauf der Anbindeleitungen und die Verteileranschlüsse.

Hinweis 1: Die Geschosse in EuroPlan müssen nicht unbedingt den physikalischen Geschossen entsprechen. Sie können (und müssen) z.B. Erd- und Obergeschoss in einem gemeinsamen Geschoss eingeben, falls Sie einen gemeinsamen Verteiler verwenden wollen. Andererseits können Sie ein physikalisches Geschoss auch aufteilen (z.B. bei Mehrfamilienhäusern).

Hinweis 2: Verteiler müssen immer in dem Geschoss angelegt werden, das sie versorgen sollen. Auch wenn ein Verteiler z.B. im Keller unter der Decke montiert ist, muss er im Erdgeschoss angelegt werden.

Eingabefelder:

Bezeichnung: Die Bezeichnung des Geschosses. Diese dient nur zur Information und wird vom Programm nicht benötigt.

öffnen: Benutzen Sie diese Buttons, um die Details zum gewünschten Geschoss zu öffnen. Alternativ können Sie das Geschoss in der Projekthierarchie anwählen.

Bearbeitungsmöglichkeiten:

Je nach Einstellung in der Programmkonfiguration wechseln Sie mit Tab oder Enter zum nächsten Feld. Mit Strg+Tab bzw. Tab verlassen Sie die Tabelle.

Mit den Buttons in der Spalte öffnen können Sie das entsprechende Geschoss öffnen. Dies entspricht einem Mausklick auf den entsprechenden Knoten in der Projekthierarchie.

Mit dem Button Geschoss löschen können Sie das Geschoss löschen, das durch den Datensatzmarkierer gekennzeichnet wird.

Wenn Sie eine Zeile mit der Maus markieren (durch Klicken auf den Datensatzmarkierer links in der Tabelle) können Sie dieses Geschoss auch mit der Taste Entf löschen.

Wenn Sie eine Zeile mit der Maus markieren können Sie dieses Geschoss mit den Buttons auf und ab eine Zeile nach oben bzw. unten verschieben.
