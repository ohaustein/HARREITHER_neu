Heizkreisanschluss

Im Fenster Heizkreisanschluss kann der Anschluss des Heizsystems gewählt werden. Üblicherweise wird ein Heizsystem direkt an einen Verteiler angeschlossen, in Spezialfällen ist es auch möglich, ein Heizsystem an ein anderes Heizsystem anzuschließen, z.B. ein WC das mit einem anderen Heizkreis mitgeheizt werden soll.

Das Fenster Heizkreisanschluss ist grob in zwei Bereiche unterteilt. Links sind in einer baumartigen Darstellung alle Verteiler und die daran angeschlossenen Heizkreise dargestellt. Rechts sind Informationen über den gewählten Anschluss und zusätzliche Optionen für den Anschluss an ein anderes Heizsystem dargestellt.

Anschluss an einen Verteiler

Markieren Sie in der Baumansicht den gewünschten Verteiler. Im Feld Information sollte dann der Text Anschluss an <Verteiler> mit dem gewählten Verteiler angezeigt werden. Wenn das Heizsystem schon an einen Verteiler angeschlossen ist, können Sie auch einen der Heizkreise des Heizsystems markieren, dies bedeutet ebenfalls den Anschluss direkt an den Verteiler und wird auch so angezeigt.

Anschluss an ein anderes Heizsystem

Markieren Sie in der Baumansicht den Heizkreis des gewünschten Systems, an den der erste Heizkreis des aktuellen Heizsystems angeschlossen werden soll. Üblicherweise wird dies der erste Heizkreis sein, die genaue Zuordnung ist aus der Tabelle in den erweiterten Einstellungen ersichtlich.

Wichtig: Das Heizsystem an das das aktuelle System angeschlossen werden soll, muss mindestens so viele Heizkreise aufweisen wie das aktuelle System, sonst können nicht alle Heizkreise das aktuellen Systems angelegt werden.

Wichtig: Die Anbindeleitungen des aktuellen Systems werden beim Anschluss an ein anderes System als Anbindeleitungen zwischen den beiden Systemen betrachtet, siehe auch die nächsten Absätze.

Weitere Einstellungen beim Anschluss an ein anderes Heizsystem

vorlaufseitig: Das aktuelle Heizsystem (S2) wird vorlaufseitig an das andere Heizsystem (S1) angeschlossen. Der Verlauf vom Verteiler aus ist dann
VL - Anb1 - Anb2 - S2 - Anb2 - S1 - Anb1 - RL

rücklaufseitig: Das aktuelle Heizsystem (S2) wird rücklaufseitig an das andere Heizsystem angeschlossen. Der Verlauf vom Verteiler aus ist dann
VL - Anb1 - S1 - Anb2 - S2 - Anb2 - nb1 - RL

benutzerdefinierte Zuordnung: Üblicherweise erfolgt die Zuordnung zwischen den Heizkreisen der beiden Heizsysteme der Reihe nach, auf Wunsch kann die genaue Zuordnung auch vom Benutzer vorgegeben werden.

Zuordnungstabelle: Geben Sie hier die genaue Zuordnung der Heizkreise an, d.h. an welchen Heizkreis im anderen Heizsystem die Heizkreise 1, 2... des aktuellen Systems angeschlossen werden sollen.
