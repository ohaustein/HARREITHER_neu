Wärmebedarf importieren

Mit der Funktion Wärmebedarf importieren können Heiz- und Kühllast aus anderen Programmen importiert werden. Aktuell steht nur das Datenformat DYGRB des Softwareherstellers Solar Computer zur Verfügung, Importfunktionen für weitere Programme werden in Zukunft folgen.

Wählen Sie die gewünschte Datei für den Import der Heizlast, wenn die Kühllast in einer separaten Datei vorliegt, aktivieren Sie das Kontrollfeld Kühllast importieren und wählen die entsprechende Daten. Es ist auch möglich, nur die Kühllast alleine zu importieren.

Beim Import werden die Dateinamen der ursprünglichen Dateien sowie Referenzen zu den einzelnen Räumen im Projekt gespeichert, damit die Daten auch zu einem späteren Zeitpunkt synchronisiert werden können, selbst wenn Geschosse oder Verteiler umbenannt worden sein sollten.
