Fußbodenheizung-Auslegungshilfe

Das Fenster Fußbodenheizung-Auslegungshilfe ermöglicht eine Abschätzung der notwendigen Vorlauftemperatur, für die eingegebenen Fußbodenheizungen.

Links im Fenster ist eine baumartige Übersicht des Projektes dargestellt, die alle Geschosse, Verteiler und Fußbodenheizungssysteme beinhaltet. Rechts sind zwei Diagramme dargestellt, in denen für einen weiten Bereich von Vorlauftemperaturen die notwendigen Verlegearten dargestellt sind. Aus diesen Diagrammen kann abgelesen werden, welche Vorlauftemperatur für welche Verlegearten notwendig ist.

Folgende Auswahlmöglichkeiten stehen zur Verfügung:

Mit dem Kombinationsfeld gewünschtes Produkt können sie das darzustellende Fußbodenheizungsprodukt auswählen. Es werden dann die Fußbodenheizungssysteme dargestellt, die dieses Produkt verwenden.

Wenn Sie einen Knoten in der Baumdarstellung markieren, werden die Kurven dieses Knotens und aller seiner Unterknoten fett dargestellt (auch wenn Sie nicht aktiviert sind). Eine Ausnahme stellt der Projektknoten dar, bei dem keine Kurven fett angezeigt werden.

Mit den Kontrollkästchen der einzelnen Knoten können Sie wählen, ob die Knoten dargestellt werden sollen.
