Programmkonfiguration

In der Programmkonfiguration können einige Parameter verändert werden, die das Verhalten von EuroPlan bestimmen.

Tastaturverhalten: Mit dem Tastaturverhalten kann festgelegt werden, ob wie bei Windows Programmen üblich mit Tab zum nächsten Eingabefeld gewechselt wird, oder ob die Taste Enter den Wechsel bewirkt. Abhängig davon werden die Tasten Enter bzw. F2 mit Zusatzfunktionen für spezielle Eingabefelder belegt.

Druckerschrift: Wählen Sie die für die Ausdrucke verwendete Schriftart. Beachten Sie, dass keine zu großen Schriften verwendet werden sollten, damit die auszudruckenden Daten tatsächlich auf der Seite Platz finden.

Ränder: Wählen Sie die Seitenränder, die bei den Ausdrucken eingehalten werden sollen.

Grafikdruck: Mit der Option alle Grafiken im gleichen Maßstab drucken kann festgelegt werden, ob für alle Grafiken der gleiche Maßstab verwendet wird, oder ob für jede Grafik der größtmögliche Maßstab gewählt wird.

Druckbereiche: Hier können die Standardwerte der Druckbereiche festgelegt werden. Beim Programmstart werden diese geladen und können danach bei jedem Ausdruck verwendet werden.

Druckstil: Mit diesem Eingabefeld kann der Standard-Druckstil festgelegt werden.

Bildschirmschriftart: Ermöglicht die Festlegung einer anderen Standardschriftart, falls die Windows Standardschrift zu groß für die verwendeten Formulare ist.
