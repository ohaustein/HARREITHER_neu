Wärmedämmkonstruktion

Das Fenster Wärmedämmkonstruktion dient zum Anlegen und Bearbeiten von benutzerdefinierten Wärmedämmkonstruktionen.

Eingabefelder:

Nummer: Die Nummer der Konstruktion muss eindeutig sein, die Konstruktionsnummern WDxx sollten für zukünftige Programmversionen freigehalten werden.

Bezeichnung: Die Bezeichnung wird vom Programm nicht benötigt und soll eine leichte Identifikation der Konstruktion ermöglichen.

PE-Folie: Wählen Sie ob die Konstruktion mit einer PE-Folie ausgeführt werden soll.

Eingabefelder der Schichten:

Bezeichnung: Geben Sie eine Bezeichnung der Schicht ein, auch diese Bezeichnung dient nur zur Information.

Material: Wählen Sie das gewünschte Material aus der Liste, falls das Material dieser Schicht im Materialbedarf berücksichtigt werden soll. Sie können zusätzliche Materialien in der Systemkonfiguration anlegen, diese müssen allerdings als Einheit m² aufweisen, damit Sie in einer Fußbodenkonstruktion verwendet werden können.

lambda: Geben Sie den Wärmeleitwert der Schicht an. Aus dem Wärmeleitwert und der Schichtdicke wird automatisch der flächenbez. Wärmedurchgangswiderstand berechnet.

d: Dieses Feld dient zur Eingabe der Schichtdicke in mm.

R: Alternativ kann auch der flächenbez. Wärmedurchgangswiderstand angegeben werden, zur Kontrolle wird die Wärmeleitfähigkeit berechnet.

Bearbeitungsmöglichkeiten:

Je nach Einstellung in der Programmkonfiguration wechseln Sie mit Tab oder Enter zum nächsten Feld. Mit Strg+Tab bzw. Tab verlassen Sie die Tabelle.

Mit F2 bzw Enter können Sie die Liste der Konstruktionen öffnen.

Mit dem Button Ok beenden Sie die Eingabe..
