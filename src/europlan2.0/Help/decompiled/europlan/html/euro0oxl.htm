Druckbereich

Das Fenster Druckbereich dient zur Festlegung der auszudruckenden Teile der Auslegung und zur Einstellung des gewünschten Druckstils.

Eingabefelder:

Druckbereiche: Sie können die einzelnen Druckbereiche aktivieren oder deaktivieren, je nach gewünschtem Umfang der Ausdrucke.

Druckstil: Es stehen unterschiedliche Druckstile zur Verfügung, die unterschiedliche viel Platz benötigen. Die komprimierten Stile verwenden weniger Seitenumbrüche, dafür werden eventuell die Druckbereichen nicht auf unterschiedliche Seiten gedruckt, die 2-in-1 Stile drucken zwei Seiten um 90° gedreht auf 1 Blatt Papier.

Systeme: Es ist auch möglich die Ausdrucke auf einzelne Heizsysteme einzuschränken. Markieren Sie die auszudruckenden Heizsysteme.

Drucken: Die gewünschten Druckbereiche werden auf dem aktuellen Drucker ausgedruckt. Wenn noch kein Drucker gewählt wurde, wird der Windows Standarddrucker verwendet.

Einrichten: Mit diesem Button wird ein Dialogfenster angezeigt, mit dem der gewünschte Drucker ausgewählt und konfiguriert werden kann.

Ansehen: Mit dem Button ansehen wird die Druckvorschau geöffnet. Dieser Button steht nur in der Funktion Auslegung ansehen zur Verfügung.

Hinweis: Die Standardwerte der Druckbereiche können in der Programmkonfiguration festgelegt werden. Benutzen Sie dazu den Menüpunkt System/Konfiguration.

Bearbeitungsmöglichkeiten:

Je nach Einstellung in der Programmkonfiguration wechseln Sie mit Tab oder Enter zum nächsten Feld.

Mit der Leertaste können Sie den Status von Kontrollfeldern ändern.

Mit dem Button Ok beenden Sie die Eingabe.
